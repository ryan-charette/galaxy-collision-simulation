# Support

Use GitHub issues for reproducible project questions, bugs, documentation gaps,
and validation concerns.

Please include:

- operating system
- compiler and CMake version
- Python version, if Python tooling is involved
- whether MPI or CUDA is enabled
- command/config used
- relevant logs or diagnostics

For numerical questions, include the solver, particle count, timestep,
softening, opening angle, expansion order, and the direct-solver comparison or
diagnostics that motivated the question.
